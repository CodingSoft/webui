# 🐳 Desarrollo con Docker Este directorio contiene configuraciones para desarrollo local usando Docker. ## 🚀 Inicio Rápido ```bash # 1. Iniciar todo ./scripts/docker-dev.sh start # 2. Abrir en navegador open http://localhost:5173 ``` ## 📋 Comandos Disponibles | Comando | Descripción | |---------|-------------| | `./scripts/docker-dev.sh start` | Iniciar entorno de desarrollo | | `./scripts/docker-dev.sh stop` | Detener todos los servicios | | `./scripts/docker-dev.sh restart` | Reiniciar servicios | | `./scripts/docker-dev.sh logs` | Ver logs de todos los servicios | | `./scripts/docker-dev.sh logs backend` | Ver logs específicos del backend | | `./scripts/docker-dev.sh build` | Reconstruir imágenes Docker | | `./scripts/docker-dev.sh clean` | Limpiar todo (incluyendo datos) | | `./scripts/docker-dev.sh status` | Ver estado de los servicios | | `./scripts/docker-dev.sh shell frontend` | Abrir shell en el frontend | ## 🌐 Accesos Una vez iniciado: - **Frontend**: http://localhost:5173 - **Backend API**: http://localhost:8080 - **Documentación API**: http://localhost:8080/docs ## 🔧 Configuración ### Variables de Entorno Las siguientes variables están configuradas por defecto: ``` ENV=dev PORT=8080 WEBUI_AUTH=False ENABLE_SIGNUP=True ``` Para personalizar, crea un archivo `.env` en la raíz: ``` ENV=dev PORT=8080 WEBUI_AUTH=True # Si quieres autenticación ENABLE_SIGNUP=True JWT_SECRET_KEY=tu-secreto-aqui ``` ### Volúmenes Los siguientes directorios se sincronizan para hot reload: - `./backend` → Contenedor backend - `./src` → Contenedor frontend - `./backend/data` → Datos persistentes ## 🛠️ Solución de Problemas ### Error de puerto en uso ```bash # Ver qué usa el puerto 5173 lsof -i :5173 # O cambiar el puerto en docker-compose.dev.yml ``` ### Reconstruir todo ```bash ./scripts/docker-dev.sh clean ./scripts/docker-dev.sh start ``` ### Ver logs en tiempo real ```bash ./scripts/docker-dev.sh logs # o específico ./scripts/docker-dev.sh logs backend ``` ## 📦 Estructura ``` docker-compose.dev.yml # Configuración principal Dockerfile.backend.dev # Dockerfile del backend Dockerfile.frontend.dev # Dockerfile del frontend scripts/docker-dev.sh # Script de gestión backend/data/ # Datos persistentes (SQLite) ``` ## 🎯 Producción Para producción, usa el Dockerfile original en la raíz: ```bash docker build -t codingsoft-ai . docker run -p 3000:3000 codingsoft-ai ``` ## 🔒 Seguridad En desarrollo: - Autenticación deshabilitada por defecto - CORS habilitado para localhost - SQLite como base de datos Para producción, habilita: - Autenticación (WEBUI_AUTH=True) - PostgreSQL (descomentar en docker-compose) - Variables de entorno seguras
